# MD FORCE: public builds

Releases of **MD FORCE**, a free 5v5 tactical shooter (Police vs Bandits).

- Download the latest Windows build from [Releases](https://github.com/magadanuhak/md-force-public-build/releases/latest).
- The game checks this repository at launch and updates itself.
- Each release carries the Windows game, the Linux dedicated server and a `manifest.json` with SHA-256 checksums.
